# Ingestion
1 - proccess documments and store
2 - the processing requires breaking these documment into small pieces with called chunking.
3 - fix-size chunking means spllit documment into equal token lengths (ex:500 token per chunk)
best ways are : semantic chunking , heirarchical chunking

# Embeddings
1 - convert each chunk to embedding
2 - every embedding is a numerical vector reperest meaning of a text
3 - when user query a seach it get embedded for search similarity which called sementic search

```bash
       ↓

       ↓

       ↓
```
